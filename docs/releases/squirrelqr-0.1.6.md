SquirrelQR 0.1.6 (versionCode 9), the first release since 0.1.5.

## What's new

- **Boxes land on the code.** Fixed the overlay mapping, so the highlight sits on the QR code in every rotation and aspect ratio.
- **Fixed framing guide.** A centred guide is shown by default, and live tracking of the code is now optional.

## Downloads

- `SquirrelQR-0.1.6-android.apk`: signed Android build (Android 8.0+).
- `SHA256SUMS.txt`.

There is no desktop build yet. Desktop screen-region and webcam scanning is on the roadmap (S3.4). Play users get the same version through the store.
